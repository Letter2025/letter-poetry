# LETTER-POETRY-PLAN-009-主题与季节策展

> 计划状态：✅ 全部完成 ｜ 创建日期：2026-08-07 ｜ 完成日期：2026-08-07 ｜ 目标：四季 + 经典主题的策展入口，首页按当前季节推荐，增强发现性与编辑感

## 一、背景

站点已有选集/作者/搜索维度；缺「文化维度」浏览入口。目标：按**季节（春夏秋冬）**与**经典主题（明月/送别/思乡/边塞/田园/咏史怀古）**策展，首页按当前季节推荐。

## 二、方案

- **数据**：`themes.json`（季节 + 主题：slug/name/title/desc/ids 精选诗 id 列表），由本地脚本从 D1 匹配候选诗真实 id 生成，**作为静态文件提交**（lib/generated + public/data，bundle 可读）。
- **页面**：
  - `/themes`：策展总览（季节 + 主题卡片）
  - `/themes/[slug]`：单个策展页（名称/简介 + 诗列表，服务端按 ids 批量查 D1）
  - 首页：按当前月份显示「当季推荐」板块（3-5 首）
  - header 导航加「策展」入口
- **精选原则**：只选库里存在的诗（全唐诗/12 选集/蒙学；宋诗、陶渊明等不在库的不选）。
- 数据库不改；策展数据低频变更，静态提交。
